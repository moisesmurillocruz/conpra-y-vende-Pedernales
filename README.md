# Compra y Vende Pedernales

PWA estatica para que la app pueda abrirse desde web e instalarse en telefonos
compatibles.

## Ejecutar localmente

```bash
npm start
```

Luego abre <http://localhost:4173>.

## Descargar la app

1. Abre la pagina desde Chrome, Edge o Safari movil.
2. Toca **Descargar app** si el boton esta disponible.
3. Si el navegador no muestra el boton, usa el menu del navegador y elige
   **Agregar a pantalla principal**.

## Validar la PWA

```bash
npm test
```
